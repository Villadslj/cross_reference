# Cross Reference for Google Docs

## Privacy Policy
Cross Reference makes changes to Google Docs documents and stores user settings in the users Google Docs property stores (document stores and user stores). Cross Reference neither exports nor collects any user data.

The list of figures feature in Cross Reference uses the PDF.js library to process documents as PDFs. This library is loaded from a CDN with a pinned version and Subresource Integrity verification, and runs entirely within the add-on dialog in the document: PDF JavaScript evaluation is disabled and the document is never exported to any external server.
